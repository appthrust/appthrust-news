今回のアップデートに含まれる主な変更をお知らせします。

## Function

- **Function コンポーネント**: [Dashboard]({{.PlatformAPIURL}}) でアプリケーションにコンポーネントを追加するときに、Function を選べるようになりました。コンテナイメージから作成し、HTTP 経由の CloudEvents で呼び出します。呼び出しがないときは 0 台まで縮小します。
- **稼働状況の表示**: Function の概要に、Function の URL、スケールの設定、現在動いている台数を表示します。
- **HTTP での公開**: コンテナと同じ手順で、Function を HTTP で外部に公開できるようになりました。

## データベース

- **使われていないときの停止**: データベースを作成するときに「Scale to zero」を選ぶと、アイドル状態が続いたら停止し、次の接続で自動的に起動します。停止までの時間と、起動後に動かし続ける最小時間を秒単位で設定できます。
- **稼働状態の切り替え**: 作成済みのデータベースでも、常に起動したままにするか、手動で停止するか、アイドル時に停止するかを切り替えられるようになりました。現在の状態も表示します。
- **スナップショット対応ストレージの選択**: スナップショットでのバックアップを有効にすると、スナップショットに対応したストレージを自動で選ぶようになりました。自分で選んだ場合はその選択を優先します。

## 開発用ワークスペース

- **ブラウザでの開発**: Project の「開発」タブからワークスペースを開始すると、アプリケーションのソースをブラウザ上の VS Code Web で編集し、プレビューで動作を確認できます。ワークスペースの中で Codex も利用できます。
- **変更の反映**: ワークスペースのブランチの差分を確認し、コミットと push、Pull request の作成まで Dashboard から行えます。

## GitHub とイメージ

- **ソース接続**: GitHub App を、テンプレートからアプリケーションのリポジトリを作るためのソース接続として登録できるようになりました。使ってよいテンプレートも指定できます。
- **レジストリ接続**: GitHub Apps の画面で、GHCR、Docker Hub、Amazon ECR などからイメージを取得するための認証情報を登録できるようになりました。登録した認証情報は、アプリケーションを作るときに Project へ取り込めます。登録時には、タグを一覧できるかどうかで認証情報を確認します。

## 初期設定

- **初期設定ウィザード**: 2 つの手順を追加しました。Dashboard や IAM などで使うプラットフォームドメインについて DNS の委任状況を確認する手順と、Argo CD が参照する GitOps リポジトリを設定する手順です。

## 修正

- 既定とは異なるホスト名で動いている Dashboard から、GitHub App を作成できない問題を修正しました。
- GitHub App を GitOps の配信に使う設定が、リポジトリとブランチを確認しないまま既定値で保存されていた問題を修正しました。保存の前に、確認と編集のための画面を表示します。
