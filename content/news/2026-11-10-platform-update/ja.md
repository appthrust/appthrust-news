今回のアップデートに含まれる主な変更をお知らせします。

## マーケットプレイス

- **マーケットプレイスからのインストール**: 組み込みアプリはマーケットプレイスのアプリになり、[Dashboard]({{.PlatformAPIURL}}) の Project のマーケットプレイスからインストール、更新、削除できるようになりました。インストール時に「自動で更新」と「バージョンを固定」のどちらかを選べます。
- **アプリの詳細ページ**: 概要、スクリーンショット、主な特長、必要条件、バージョンを、Dashboard の中の 1 ページで確認できるようになりました。名前と説明は表示言語に合わせて表示し、アプリにその言語がない場合は英語で表示します。
- **ステージングの有無の選択**: インストール時に、本番だけで動かすか、専用のリソースとデータを持つステージングも動かすかを選べるようになりました。インストール後もアプリの詳細ページで切り替えられ、GPU を使う Inference は既定で本番だけで動きます。

## apth CLI

- **アプリのインストール**: `apth app-installations` に `list`、`get`、`install`、`update`、`uninstall` を追加し、マーケットプレイスのアプリを Dashboard を開かずに操作できるようになりました。`--wait` を付けると完了まで待ち、更新中に状態が一時的に Degraded になっても失敗とはせず、Ready になるまで待ちます。
- **ログインコードの有効期限**: `apth login` が、承認用コードの有効期限を表示するようになりました。

## アプリケーション

- **ランタイムの脆弱性への対応**: 「Next.js」テンプレートから新しく作るアプリケーションは、Dashboard からでも apth からでも、既定でマネージドランタイムの Node.js 24 を使い、ランタイムの更新を自動で取り込みます。手動更新にしたランタイムでも、重大度 Critical / High のアドバイザリは猶予期間のあとに修正版へ更新されます。対象のコンポーネントがあると Project の概要に「セキュリティ更新」バッジが表示され、状況はそこから開く画面や `apth runtime-advisories list` で確認できます。

## クラスター

- **クラスターの作成**: 作成画面を「何を作る」「構成」「確認して作成」の 3 ステップにまとめました。選べる値だけを表示し、使えないランタイムには理由を添えます。

## サインインと権限

- **グループとロールによるアクセス管理**: チームに代わり、グループとロールでアクセスを管理するようになりました。Project の「アクセス」タブで、ユーザーやグループに管理者・編集者・閲覧者のロールを割り当てます。グループは Dashboard の「設定」ページの「グループ」で作成します。
- **GitHub / Google でのサインイン**: 管理者が設定すると、GitHub または Google のアカウントでサインインできるようになります。
- **グループの再マッピング**: 外部の ID プロバイダーのグループに対応付けたグループを、Dashboard の「再マッピング」で別の値に付け替えられるようになりました。付け替えの途中で権限が外れることはありません。
- **AI ポリシーの管理**: プラットフォーム管理者は、組織の AI ポリシーを Dashboard の「AI ポリシー」画面で作成・編集できるようになりました。各 Project では「AI」タブでポリシーを割り当て、さらに制限を加えられます。

## 修正

- アプリケーションテンプレートがすべて「利用不可」と表示される問題、空のアプリケーションの状態が「unknown」のままになる問題、テンプレートから作成したアプリケーションがマーケットプレイスアプリの定義でデプロイされることがある問題を修正しました。
- 使えるソースの接続が複数あるとき、アプリケーションの作成画面が名前順で最初の接続を自動で選んでいた問題を修正しました。今後は接続を選ぶまでリポジトリの作成先が決まりません。
- Project の概要が、アプリケーションの数をもとに GitOps を「接続済み」、Argo CD を「同期済み」と表示していた問題を修正しました。
