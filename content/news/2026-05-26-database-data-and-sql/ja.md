データベースの中身を Dashboard で確認できるようになりました。

## できること

- テーブルを選ぶと、その行が「テーブルプレビュー」に表示されます。
- 「クエリ」では読み取り専用の SELECT 文か WITH 文を 1 つ、「バッチ」では DDL や DML をまとめて実行できます。
- 主キーのあるテーブルでは、行の編集や削除から SQL を作り、バッチで実行するか「変更」タブの下書きに回せます。
- 「アドバイザー」タブでは、インデックスの候補から「変更を作成」で変更の下書きを作れます。

## 使い方

1. [Dashboard]({{.PlatformAPIURL}}) で Project を開き、サイドバーの「データベース」からデータベースを選びます。
2. 「データ」タブでテーブルを選びます。
3. 「クエリ」か「バッチ」で SQL を書き、「実行」か「バッチを実行」を押します。

## 注意点

- 「マネージド（クラウド）」のデータベースには、「データ」と「アドバイザー」のタブがありません。
- バッチは CloudNativePG のデータベースでだけ使えます。分離ランタイムの Project では、バッチも Neon のデータ表示も使えません。
- Neon のブランチのデータは読み取り専用で、編集権限のあるメンバーが「データ閲覧を有効にする」を押すと表示されます。
- クエリやバッチの実行には、Project の「管理者」か「編集者」のロールが必要です。
