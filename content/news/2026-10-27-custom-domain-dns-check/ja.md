Project の「ドメイン」タブで、カスタムドメインの DNS 設定と証明書の状態を確認できるようになりました。アプリケーションを独自のドメインで公開する方に向けた機能です。

## できること

- ドメインごとのカードに、「有効な設定」か「無効な設定」かと、「証明書発行済み」などの証明書の状態が表示されます。
- 設定が無効なときは、理由と、DNS プロバイダーで設定するレコードの種類・名前・値が表示され、値をコピーできます。
- 「DNS の詳細」では、公開 DNS で実際に見えているレコードを確認できます。
- Project のドメインの下で発行されたホスト名も、転送先や公開 URL とあわせて表示されます。

## 使い方

1. [Dashboard]({{.PlatformAPIURL}}) で Project を開き、「ドメイン」タブを選びます。
2. カスタムドメインのカードで状態を確認します。外部 DNS のドメインは自動で確認されます。
3. 「無効な設定」と表示されたら、表の値をコピーし、DNS プロバイダーでそのレコードを設定します。
4. 「更新」を押して、もう一度確認します。

## 注意点

- 転送先がまだないドメインには、設定するレコードは表示されません。
- Project によっては、カスタムドメインをまだ追加できないことがあります。
