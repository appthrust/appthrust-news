今回のアップデートに含まれる主な変更をお知らせします。

## apth CLI

- **ログインとアプリケーションの操作**: `apth login` で、ブラウザーで承認するデバイスログインができるようになりました。`apth apps create`、`get`、`wait`、`publish`、`logs` と `apth apps env get|set|unset` を使うと、アプリケーションの作成から公開、環境変数の設定までをターミナルで行えます。
- **アクターの操作**: `apth actors` で、アクタータイプとアクターの一覧表示、作成、呼び出しなどができます。アクターを呼び出すときは、`apth login` のクライアント資格情報によるログインを使います。
- **エージェントスキル**: アプリ開発用のエージェントスキルを `apth` に同梱しました。`apth skills install` で、Claude Code、Codex、OMP のスキルディレクトリにインストールできます。
- **ログイン状態の確認とエラー表示**: `apth whoami` は、保存している認証情報が有効かどうかを Platform API に問い合わせて表示するようになりました。エラーには対処方法を示す `Hint:` 行が付きます。デリバリーの準備中に返る一時的なエラーは、SDK と `apth` が自動で再試行します。

## クラスター

- **Runtime タブ**: [Dashboard]({{.PlatformAPIURL}}) のクラスター詳細に Runtime タブを追加しました。クラスター全体の判定、コントロールプレーンやワーカー、ネットワーク、ストレージ、パッケージといった層ごとの状態、最近の変化、マシンの一覧をまとめて確認できます。
- **接続ページの見直し**: クラスター間の接続ページを、接続の健全性マトリクスを中心とした構成に作り直しました。すべての接続が確立しているのに「設定済みメンバーがクラスター一覧にない」と表示され、マトリクスが空になる問題も修正しました。

## データベース

- **共有ランタイムでのデータブラウザー**: 共有ランタイムのセキュリティポリシーにより使えなかったデータタブで、テーブルと行の閲覧、インデックスの提案、読み取り専用の SQL コンソールを使えるようになりました。スクリプトの実行は引き続き利用できません。
- **詳細ページの一本化**: データベース一覧や Application のデータタブのリンクは、Project 内のデータベース画面に移動するようになりました。サンプルの値を表示していた以前の詳細ページは廃止しました。

## Dashboard

- **日本語表示の改善**: 英語と日本語が混ざって表示されていた画面の文言を見直しました。クラスター詳細、Project のランタイム、Application Branch の詳細などが日本語で表示されます。訳がない文は、途中まで訳した形ではなく英語のまま表示します。

## 修正

- メンバーを招待すると、招待リンクが表示されないまま「Active」のメンバーとして追加される問題を修正しました。登録されていないメールアドレスには招待リンクを表示します。
- データベースの Logs タブにログが表示されない問題と、コンポーネントのログの読み込みに時間がかかってタイムアウトすることがある問題を修正しました。
- Application Branch の表示名を変更したあと、ページの見出しが古い名前のままになる問題を修正しました。
- AI 開発で、接続が切れたあとや下書きを開き直したときに実行中の AI タスクに再接続せず、承認ダイアログが表示されない問題を修正しました。
- 開発ワークスペースで「Commit and push」が失敗する問題、変更一覧がエラーになる問題、Restart runtime を押してもスリープから戻らない問題を修正しました。
