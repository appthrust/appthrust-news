テンプレートからアプリケーションを作るための接続を、Dashboard で設定できるようになりました。GitHub 接続はアプリリポジトリの作成に、レジストリ接続はプライベートなイメージの取得に使います。

## できること

- Project の「連携」で、テンプレートからアプリを作成できる状態かを確認できます。
- アプリ作成用の GitHub App を Dashboard から作成して接続にできます。使えるテンプレートは接続ごとに絞り込めます。
- GHCR、Docker Hub、Amazon ECR などの pull 用認証情報を、レジストリ接続として登録できます。登録時にイメージのタグ一覧を取得して、認証情報を確かめます。

## 使い方

1. [Dashboard]({{.PlatformAPIURL}}) で Project の「設定」から「連携」を開き、「接続一覧」を押します。
2. 「アプリ作成用 GitHub App を作成」で作成先を選び、GitHub で App を作成してインストールします。Dashboard に戻ったら「接続として有効化」を押します。
3. 「レジストリ接続」の「レジストリを追加」で種別、イメージパス、ユーザー名、トークンを入力し、「レジストリ接続を作成」を押します。

## 注意点

- GitHub App の作成先は、「GitHub を接続」でサインインした GitHub アカウントから見えるユーザーか Organization から選びます。App は GitHub 上でインストールするため、その作成先に App をインストールできる GitHub アカウントで操作してください。
- レジストリ接続には、指定したイメージパスのタグ一覧を取得できるユーザー名とトークンが必要です。
- このページの接続は特定の Project に属さず、複数の Project で使えます。
- 1 つの Project だけで使うイメージは、「運用」の「レジストリ」で「リポジトリを作成」を押し、「外部レジストリ」を選んで登録します。Project の「管理者」か「編集者」のロールが必要です。
- 「認証情報を再検証」でアクセスを確かめても、保存済みの認証情報は変わりません。
