アプリケーションのソースをブラウザーで編集できる開発ワークスペースを使えるようになりました。手元に開発環境がなくても、編集から Pull Request の作成までを Dashboard で進められます。

## できること

- VS Code Web でソースを編集し、プレビューでアプリの動きを確かめられます。
- 「AI エージェントに編集を依頼」で AI エージェントにソースを編集させたり、「Claude Code」のターミナルを開いたりできます。
- 「変更」で変更されたファイルを確認し、「コミットして push」でワークスペースのソースブランチに push できます。
- 「コミットして Pull Request を作成」で、GitHub に Pull Request を作成できます。

## 使い方

1. [Dashboard]({{.PlatformAPIURL}}) のサイドバーの「アプリケーション」からアプリケーションを開き、「開発」タブを選びます。
2. 「新規ワークスペース」を押して「ワークスペース名」を決め、「ワークスペースを作成」を押します。
3. 準備ができたらソースを編集し、「変更」で内容を確認してから「コミットして Pull Request を作成」を押します。

## 注意点

- ワークスペースの作成には、Project の編集者か管理者のロールが必要です。
- コミットと Pull Request の作成には、アプリケーションに Source repository が接続されている必要があります。
- プレビューでは、ソースの package.json にある dev スクリプトをポート 3000 で実行します。
- Project の AI ポリシーやインストールの構成によっては、ワークスペースや AI エージェントを使えない場合があります。
