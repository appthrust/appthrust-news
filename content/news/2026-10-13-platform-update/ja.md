今回のアップデートに含まれる主な変更をお知らせします。

## Dashboard

- **新しいナビゲーション**: [Dashboard]({{.PlatformAPIURL}}) のヘッダーに「チーム / Project / アプリケーション / コンポーネント」の階層を表示し、そこからチームや Project を切り替えられるようになりました。サイドバーは開いているページに合わせてチームと Project のメニューを切り替え、Project が多い場合は名前で検索できます。
- **アプリケーション一覧**: Project の「アプリケーション」ページは、一覧を先頭に表示するようになりました。進み具合は、準備が終わっていないアプリケーションの分だけ表示します。

## アプリケーション

- **停止中のアプリの起動画面**: アクセスがなく停止しているアプリを開くと、起動を待つあいだ起動中であることを示す画面をすぐに表示するようになりました。起動が終わると、通常どおりアプリにつながります。
- **公開イメージからの作成**: 公開されているコンテナイメージであれば、レジストリの認証情報を登録しなくても `apth apps create --image` でアプリケーションを作成できるようになりました。認証が必要なイメージの場合は、登録に使う `apth registries create` コマンドを案内します。Dashboard で選べるのは、Project に登録済みのイメージです。
- **ポートの自動判定**: Dashboard でコンテナのポートを省略すると、イメージの `EXPOSE` からポートを判定するようになりました。判定できない場合は、ポートを指定するか Dockerfile に `EXPOSE` を追加するよう案内します。apth では `--port` で指定します。

## データベース

- **Neon データベースのデータタブ**: Neon のデータベースでも、データタブでデータを閲覧できるようになりました。編集権限のあるメンバーがブランチのデータアクセスを有効にすると、そのブランチのデータも読み取り専用で確認できます。分離されたランタイムを使う Project では利用できません。
- **概要ページと作成フォーム**: データベースの概要ページの先頭に、状態、セットアップの進み具合、接続情報をまとめました。セットアップが 15 分を超えると警告を表示します。作成フォームも項目を整理しました。
- **初期スキーマの承認**: 作成したばかりの空のデータベースに適用する初期スキーマは、既定のポリシーでは承認なしで適用するようになりました。承認が必要な設定にしている場合は、承認待ちであることを表示します。

## クラスター

- **可用性モードの切り替え**: Project に「クラスター」タブを追加しました。Single と HA の可用性モードを切り替えられ、クラスターが報告している現在のモードとワーカープールの状態を確認できます。選べるモードはクラスターの構成によって異なり、共有ランタイムの Project では変更できません。

## apth CLI

- **AppThrust Cloud へのログイン**: `apth login` で AppThrust Cloud のアカウントにもサインインできるようになりました。Cloud のプロファイルでも `apth whoami` と `apth logout` を使えます。

## 修正

- 停止中のアプリが起動する前に、リクエストがタイムアウトすることがある問題を修正しました。
- コンテナの作成ウィザードで入力した環境変数が保存されない問題を修正しました。
- イメージの更新中に「ビルド中」と表示され続ける問題を修正しました。更新中は「デプロイ中」と表示し、起動に失敗したワークロードは理由とログを表示します。
- 環境変数を複数の画面で同時に編集すると、互いの変更を消してしまうことがある問題を修正しました。あわせて、プレビューで編集中の内容が本番に保存されることがある問題と、シークレットの値が入力中に表示される問題も修正しました。
