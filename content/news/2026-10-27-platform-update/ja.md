今回のアップデートに含まれる主な変更をお知らせします。

## アプリケーション

- **状態別の一覧とラベル**: [Dashboard]({{.PlatformAPIURL}}) のアプリケーション一覧を「要対応」「進行中」などの状態ごとにまとめ、ラベルで絞り込めるようにしました。ラベルは Dashboard のほか `apth applications set-labels` でも設定できます。
- **作成フォームの刷新**: アプリケーションの作成フォームを「何を作る」「オプション」「確認して作成」の 3 ステップにしました。テンプレートはカテゴリごとに並び、すべてのカテゴリをまとめて検索できます。
- **スケジュール実行のジョブ**: アプリケーションに「ジョブ（スケジュール実行）」コンポーネントを追加できるようになりました。作成後も、コマンド、スケジュール、タイムゾーンなどを「ジョブ設定」から変更できます。

## ドメイン

- **DNS 設定のチェック**: Project の「ドメイン」で、カスタムドメインの DNS が正しく設定されているか、証明書が発行済みかを確認できるようになりました。設定が正しくない場合は、登録すべき DNS レコードをコピーできる形で表示します。

## データベース

- **特定時点への復元**: 「バックアップ設定」で継続アーカイブを有効にすると、復元可能期間内の任意の時点を指定してデータベースを復元できます。現時点では、バックアップ先がボリュームスナップショットで、インスタンスが 1 つのデータベースが対象です。

## ネットワークとアクセス

- **外向き通信の許可リスト**: AppThrust Enterprise をインストールした環境では、Project の「ネットワーク」設定で、ワークロードが接続できる外部のドメイン名や CIDR を指定できるようになりました。拒否された通信の記録を有効にすると、同じ画面で一覧できます。
- **アクセスキー**: Project のアプリ、ローカル開発、外部サービスから同じ方法で使える API キーを、Project の「設定」にある「アクセスキー」や `apth access-keys` で発行、一時停止、失効できるようになりました。シークレットは発行時に一度だけ表示されます。
- **監査ログ**: Dashboard の「監査」から、操作履歴を確認できるようになりました。確認できるのは、その Project の管理者と、監査者またはプラットフォーム管理者のロールを持つユーザーです。期間や条件で絞り込み、各イベントを展開して詳細を見られます。

## 組み込みアプリ

- **クラスター内で動く LLM**: 組み込みアプリ「LLM」を追加しました。Knowledge の回答生成を Project のクラスター内の CPU モデルで行えるため、外部の AI サービスの資格情報を設定しなければ、質問や回答はクラスターの外に出ません。

## 公開

- **メンテナンス画面**: アプリケーションに接続できないときや、アプリケーションが起動に失敗し続けているときは、素の 503 エラーではなく日本語と英語のメンテナンス画面を表示するようになりました。アプリケーション自身が返したエラーはそのまま届きます。

## 修正

- データベースに指定したストレージ容量が反映されず、1Gi で作成される問題を修正しました。作成済みのデータベースの容量は変わりません。
- バックアップから復元したデータベースが Ready にならない問題と、復元したデータベースがあると元のアプリケーションをリリースできなくなる問題を修正しました。
- Project のドメインを使ったアプリケーションの作成や公開が、予約済みのドメインとして拒否される問題を修正しました。
- アプリケーションの作成が途中で失敗したとき、ソースが保存済みでも「何も作成されていない」と表示される問題を修正しました。保存済みのソースから作成を続けられます。
