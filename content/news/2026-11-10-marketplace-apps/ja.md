マーケットプレイスには現在 16 のアプリがあります。用途ごとに紹介します。インストールは [Dashboard]({{.PlatformAPIURL}}) のマーケットプレイスから行えます。

## チームで使う

- **Home**: Project にインストールした標準アプリを 1 か所にまとめて表示します。
- **Directory**: 組織のメンバー、グループ、プロフィールを確認できます。
- **Memo**: Markdown の記事を書いて組織内で共有できます。著者のフォローや「いいね」もできます。
- **Contacts**: 名刺を読み取って共有の連絡先にし、チームの誰が誰とつながっているかを確認できます。
- **Peer Bonus**: 毎週、同僚にポイントと感謝を送れます。月ごとに締めて、給与計算に使える明細にまとめます。
- **Issues**: AppThrust の不具合や作業項目を、キーボード中心のボードで報告・管理できます。
- **AppThrust News**: このアプリです。AppThrust からのお知らせを届けます。

## AI を使う

- **AI Gateway**: Project の AI ポリシーに従って、許可されたプロバイダーへチャット補完を振り分け、呼び出しを記録します。
- **Knowledge**: Notion、esa、手元のドキュメントを横断して検索し、質問できます。
- **LLM**: Project 内で動くチャットモデル（CPU）です。プロンプトや文書の内容はクラスタの外に出ません。
- **Embedding**: Knowledge の検索に使うテキスト埋め込みを Project 内で提供します。内容はクラスタの外に出ません。
- **Inference**: OpenAI 互換のチャット補完を Project 内で提供します。GPU が必要です。
- **Vision**: OCR や画像理解のためのチャット補完を Project 内で提供します。GPU が必要です。

## つくる

- **Builder Console**: クラスタの詳細に触れずに、アプリケーションのビルドとリリースを行えるコンソールです。
- **Internal Tool Builder**: Project 内のデータを使って、テーブル、フォーム、ダッシュボードを作れます。
- **Agent Guide**: コーディングエージェントが `apth` と `apthctl` でこの Project を操作できるように、環境に合わせたガイドとスキルを提供します。

GPU が必要なアプリは、GPU を備えた環境でのみ動作します。
