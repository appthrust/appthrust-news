AppThrust は、会社で使うアプリを動かすための基盤です。アプリを置くサーバー、データベース、公開用の URL、サインインをまとめて用意するので、利用する人はブラウザーで開くだけで使えます。作る人は、サーバーの準備をせずにアプリを公開できます。

いま読んでいるこの AppThrust News も、AppThrust の上で動いているアプリのひとつです。

## 3 つの使い方

| 使い方 | 向いている人 | すること |
| --- | --- | --- |
| アプリを使う | 全員 | 会社のアカウントでサインインし、Project に入っているアプリを開きます。 |
| アプリを入れる | Project の管理者・編集者 | マーケットプレイスから既製のアプリを選び、「インストール」を押します。 |
| アプリを作って公開する | 開発する人 | 自分のアプリを Project に置き、URL を付けて公開します。 |

開発の経験がなくても、1 つ目の「アプリを使う」だけで十分に使えます。

## 最初に覚える言葉

| 言葉 | 意味 |
| --- | --- |
| Dashboard | AppThrust の管理画面です。ここからすべての操作ができます。 |
| Project | アプリとデータをまとめる単位です。部署や用途ごとに分けます。見えるのは、自分にロールが割り当てられた Project だけです。 |
| アプリケーション | Project の中で動くアプリです。マーケットプレイスから入れたものも、自分たちで作ったものも、同じ一覧に並びます。 |
| マーケットプレイス | 既製のアプリのカタログです。選んでインストールすると、その Project のアプリケーションになります。 |
| ロール | Project でできることの範囲です。「管理者」「編集者」「閲覧者」の 3 つがあります。 |

## アプリを使う

1. [Dashboard]({{.PlatformAPIURL}}) を開き、会社のアカウントでサインインします。
2. 自分の Project を選び、「アプリケーション」を開きます。
3. 使いたいアプリを開きます。アプリの中では、ヘッダーの「アプリを切り替える」から、同じ Project のほかのアプリに移れます。

アプリはすべて同じアカウントで開けます。アプリごとに ID やパスワードを作る必要はありません。

## アプリを入れる

Project の「マーケットプレイス」には、インストールするだけで使えるアプリが並んでいます。概要とスクリーンショットを見て選び、「インストール」を押すと、数分で Project のアプリケーションに加わります。

アプリは、インストールした Project の中だけで動きます。データもその Project のものとして保存されます。

## アプリを作って公開する

開発する人は、自分のアプリを AppThrust に置けます。用意されるものは次のとおりです。

- **動かす場所**: コンテナイメージを指定するか、テンプレートから作ります。新しいバージョンは段階的にリリースされます。
- **データベース**: アプリと一緒に作成でき、バックアップ、復元、中身の確認を Dashboard で行えます。
- **公開用の URL**: Project のドメインか、独自のドメインで公開できます。証明書は自動で用意されます。
- **運用に必要なもの**: ログ、メトリクス、環境変数、監査ログを Dashboard で確認できます。
- **コマンドライン**: ターミナルやコーディングエージェントからは、CLI の `apth` で同じ操作ができます。入手先は [https://github.com/appthrust/cli](https://github.com/appthrust/cli) です。

Dashboard のヘッダーにある AI アシスタントに、開いている Project やアプリの状態を日本語で質問することもできます。

## 困ったとき

- **Project が見えない**: その Project の管理者に、「設定」の「アクセス」タブで自分を追加してもらってください。
- **アプリが開けない**: 「アプリを起動しています」と表示されたときは、そのまま待つと開きます。開かないときは、Dashboard の「アプリケーション」でそのアプリの状態を確認してください。
- **新しい機能を知りたい**: この AppThrust News に、機能の追加や変更のお知らせが届きます。未読のお知らせには一覧で印が付きます。
